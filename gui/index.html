ADB OVER WI-FI

Conectar via Wi-Fi

No Android, abra Depuração sem fio → Parear dispositivo com código. Informe o IP, a porta de pareamento e o código exibidos. A porta de conexão é diferente; se ficar vazia, tentaremos encontrá-la via mDNS.

Preencha IP, porta e código para gerar o QR.

O QR contém os dados de pareamento em formato JSON para leitura/cópia. O app executará adb pair e depois tentará conectar o dispositivo.
